# 🏦 Bank of Katihar — Bank Management System

A modern web-based Bank Management System built with **Python Flask, SQLite, HTML, CSS, and JavaScript**.

## 🌐 Live Demo

🔗 https://bank-of-katihar.onrender.com

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 📊 Banking Dashboard
- 💰 Account Balance Management
- 💸 Money Transfer
- 🧾 Transaction Management
- 🗄️ SQLite Database
- 🎨 Modern Responsive UI
- ☁️ Render Deployment

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Deployment:** Render
- **Version Control:** Git & GitHub

🚀 Run Locally
Clone the repository
git clone https://github.com/Shabab991/bank-of-katihar.git
cd bank-of-katihar
Create virtual environment

Windows:
python -m venv .venv
.venv\Scripts\activate

macOS/Linux:
python3 -m venv .venv
source .venv/bin/activate

Install dependencies
pip install -r requirements.txt

Run the application
python app.py

Open:
http://127.0.0.1:5000

🔐 Security
The application includes user authentication and protected banking functionality.
For production use, additional security measures such as CSRF protection, rate limiting, secure secret management, stronger session management, and a production-grade database are recommended.
